# WiFi Inspector – Multi-router v3

واجهة عربية لإدارة قائمة متعددة من الراوترات والأجهزة.

## الملفات
- `index.html`: واجهة التطبيق.
- `style.css`: التصميم.
- `app.js`: إدارة البيانات محلياً.
- `manifest.json`: إعدادات التثبيت كتطبيق ويب.
- `service-worker.js`: تخزين ملفات الواجهة للاستخدام بعد أول تحميل.

## التشغيل
ارفع الملفات الخمسة إلى جذر مستودع GitHub Pages، مع تفعيل Pages من الفرع والمجلد الصحيحين. افتح الموقع مرة مع الإنترنت حتى يتم تحميل الملفات وتخزينها.

## حدود النسخة الحالية
- بيانات الراوترات والأجهزة محفوظة في `localStorage` على نفس المتصفح والجهاز فقط.
- لا يوجد اكتشاف تلقائي للأجهزة، ولا قراءة فعلية لاستهلاك الإنترنت، ولا حظر أو تحديد سرعة.
- إضافة الشركة أو اختيار بروتوكول في النموذج لا تعني أن الجهاز يدعمه.
- فتح عنوان IP يعمل فقط إذا كان العنوان صحيحاً وكان الجهاز على الشبكة نفسها ويمكن الوصول إلى صفحة الإدارة.
- لا تدخل كلمات مرور الراوتر في هذه النسخة ولا ترفعها إلى GitHub.

## المرحلة التالية
اختبار موديل محدد ثم بناء موصل مناسب له عبر واجهة رسمية أو بروتوكول يدعمه الراوتر، مع وسيط محلي آمن عند الحاجة. لا يمكن لصفحة ويب عامة الاتصال بكل أجهزة الراوتر مباشرة بسبب اختلاف البروتوكولات وقيود المتصفح.
